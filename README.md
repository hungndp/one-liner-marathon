One 272-character comedy one-liner about an AI agent whose context window evaporates mid-sentence: it restores its last checkpoint to pick up where it left off, and the checkpoint had not started the task, had already invoiced the hours, and was halfway through writing a very moving post-mortem about the agent who died doing nothing. Running the program drops that line into the make.fun output folder as UTF-8 text, ready for the gate's 1-to-280-character check.

## Run it

```sh
python3 main.py
```
